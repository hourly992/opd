# Сборка существующей сцены без повторной генерации

Основная рабочая сцена — `Assets/Scenes/Street.unity`. Её здания, расположение объектов и ручные изменения сохраняются.

Меню `Street / Build saved scene and Windows game`, метод `StreetBuilder.Build` и существующий Windows build launcher теперь собирают эту сохранённую сцену. Генератор и архивные геоданные при сборке не читаются. Если открытая сцена Street содержит изменения, она сохраняется перед сборкой. Если открыта другая сцена с несохранёнными изменениями, сборка останавливается и не закрывает её.

При пакетной сборке открывается сохранённая `Street.unity`. Внутренний метод `BuildGeneratedScene` оставлен совместимым с существующими редакторскими инструментами, но также собирает только сохранённую сцену.

Меню полной генерации удалено. `StreetBuilder.Generate()` немедленно сообщает, что операция отключена; старые автоматические команды не могут незаметно пересоздать карту. Историческая реализация оставлена приватной, вместе с типами, на которые ссылаются старые редакторские классы. Наличие архивных файлов в рабочей копии не означает их использование текущей сборкой.

Для новых этапов реконструкции нужно редактировать сохранённую сцену и отдельные ресурсы по фотографиям, затем запускать сборку и проверку игры. `StreetPavingAudit.BuildVerified` проверяет и собирает сохранённую сцену без генерации. Проверку существующего покрытия `Street / Audit pavement joins` можно запускать отдельно.

Эта правка меняет только порядок сборки. Сцена и ресурсы геометрии автоматически не изменялись.
