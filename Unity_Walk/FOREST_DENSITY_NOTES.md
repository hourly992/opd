# Уплотнение существующих лесных участков

Изменён только генератор леса `GeographicLandscapeBuilder.cs`; исходные шесть полигонов `wood`, их координаты и `sourceSha256` не менялись. Отдельные стволы по-прежнему реконструируются внутри подтверждённой границы леса, а не выдаются за измеренные деревья.

- Целевая плотность: одно дерево на 18 м² вместо 48 м². Для исходных площадей это суммарно 1507 деревьев, около 2,70 от предыдущих 559. Фактическое число может быть ниже из-за дорог, зданий, новых подходов и площадок; его нужно брать из лога генерации и отчёта игры.
- Появились три возрастных яруса: молодые деревья (примерно 30%, также у кромки), основной полог и менее частые выступающие деревья. Высота задаётся масштабом существующих общих префабов; точные высоты и породы в OSM не зафиксированы.
- Позиции не образуют геометрическую сетку. Сохраняется воспроизводимая случайная выборка, плотность и возраст слегка группируются непрерывным пространственным шумом. Пространственный хеш используется только для поиска соседей, а не для размещения по узлам. Минимальная дистанция между новыми стволами зависит от ярусов: около 2,28–3,64 м, без совпадения оснований.
- Кустарник внутри тех же полигонов: цель 0,8 куста на дерево вместо 0,5, промежуток между кустами не менее 1,74 м. У стволов оставлен небольшой зазор; кусты могут естественно находиться под кронами. Новые городские посадки за пределами лесных полигонов не добавляются.
- Помимо `StreetBuilder.CanPlant`, перед посадкой проверяются фактически созданные коллайдеры подходов, дорог, площадок и прочих объектов: центр и восемь точек по контуру отпечатка. Основная земля `Grass`, Terrain и стволы исключены из этой проверки. Новые дорожки и площадки должны создаваться до генерации леса.
- Все модели и материалы остаются общими, GPU Instancing и существующие LOD сохраняются. Только у экземпляров лесных деревьев переключение на дешёвые уровни происходит раньше: лиственные 0,55 / 0,27 / 0,11 / 0,014; хвойные 0,36 / 0,12 / 0,014. Высокодетальные городские деревья этим не затрагиваются. LOD0 и материалы ближних деревьев сохранены без упрощения; количество, позиции и масштабы растений не меняются этой корректировкой.

Пороги уточнены после уплотнения: фактические сохранённые меши лиственного дерева содержат 99924 / 35991 / 13092 / 2511 треугольников, хвойного — 31596 / 7090 / 5934. Для лиственных переход к дальнему LOD3 вместо LOD2 уменьшает геометрию примерно в 5,2 раза; основная экономия хвойных — переход с LOD0 на LOD1 (примерно в 4,5 раза). Дешёвые уровни достигаются раньше по относительному размеру на экране, а не удалением растений. Повторный замер готовой игры необходим; улучшение времени кадра заранее не заявляется.

Общая Unity-сборка и проверка игры выполнены: 1507 деревьев, 1205 кустов, шесть полигонов, `passed: true`. Повторный синхронизированный замер `Camera.Render` внутри леса на RTX 5060 при 1600×900: медиана 17,75 мс, p95 18,13 мс; до уточнения LOD медиана составляла 23,40 мс. Количество растений сохранено. Это время рендера с чтением одного пикселя, без игровой симуляции. Подробности и игровые кадры: [COURTYARDS_LIGHTING.md](COURTYARDS_LIGHTING.md).
