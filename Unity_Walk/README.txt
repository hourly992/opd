УЛИЦА ДУНИНА-ГОРКАВИЧА, ХАНТЫ-МАНСИЙСК — ВЕРСИЯ 0.1

Запуск готовой игры: Build/StreetWindows/DuninaGorkavicha.exe.
Также можно открыть «Запустить улицу.cmd» или «Запустить игру.cmd» в родительской папке.
Unity для запуска не требуется. При переносе копируйте всю папку StreetWindows.

WASD или стрелки — ходьба. Мышь — обзор. Esc — меню с продолжением прогулки и выходом.

Проект для редактирования: Unity 6.6 (6000.6.7f1), сцена Assets/Scenes/Street.unity.
Сцена содержит готовую геометрию улицы. Откройте её и нажмите Play.
Для пересоздания сцены и сборки игры используйте меню Street / Build street and Windows game или Build_Windows.cmd при закрытом редакторе проекта.

Это первая приблизительная реконструкция: основа улицы и контуры зданий взяты из OpenStreetMap; дом №5 перенесён из ранее созданной подробной модели, остальные здания пока упрощены. Рельеф, благоустройство и фасады соседних домов приблизительны.
Подробнее об исходных данных, лицензиях и проверках — STREET_README.md.
