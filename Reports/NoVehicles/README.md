# Улица Дунина-Горкавича без машин

Исходная версия для сравнения — коммит 46cc1ab, первый осенний проход в PR №2.

## Что изменилось

- Из сохранённой игровой сцены удалены все 44 машины вместе с моделями, LOD и коллайдерами экземпляров. Списки машин очищены во всех 19 парковочных зонах.
- Планировка домов, площадок, парковок и проходов совпадает по контрольному хешу сцены.
- Проверка StreetQA теперь требует ноль машин и ноль ссылок на них на парковках. Проверки покрытия и въездов сохранены. Правило о формате отчёта закреплено в AGENTS.md.

Кадры из Windows-игры, 1600 × 900, одна позиция и направление на каждый ракурс, вертикальный FOV 62°, DXR включён.

## Проверки

- Windows, Unity 6000.6.7f1. Машин 0, ссылок на них 0, отсутствующих материалов 0. Пройдены 15 из 15 маршрутов, 96 из 96 стыков и 4859 из 4859 проб покрытия парковок. В сумерках включились 8 фонарей.
- Проверены DXR и его отключение. Движение листьев прошло отдельный прогон с 3 из 3 проходов.
- В 12570 пробах геометрии нет щелей и скачков высоты. У крыльца №6 проба по-прежнему попадает на фаску ступени.
- Linux x86-64 собрана. Первый запуск StreetQA на Ubuntu остановился по лимиту времени программного рендера. [Повторная проверка Ubuntu](https://github.com/hourly992/opd/actions/runs/43022350397)

## Производительность

RTX 5060, DXR, игровой вертикальный FOV 60° в обеих сборках. По 42 кадра на ракурс после прогрева. Время включает рендер кадра и чтение контрольного пикселя, значения в миллисекундах.
