# opd

Русскоязычный проект первой игровой версии улицы Дунина-Горкавича в Ханты-Мансийске. Движок — Unity 6.6 (6000.6.7f1), язык — C#.

## Папки и исходники

- Git-репозиторий находится в корне `opd`. `Unity_Walk` — папка проекта Unity внутри этого репозитория.
- Основная сцена: `Unity_Walk/Assets/Scenes/Street.unity`.
- Генератор улицы: `Unity_Walk/Assets/Editor/StreetBuilder.cs`.
- Скрипты ходьбы, интерфейса и проверки: `Unity_Walk/Assets/Scripts/`.
- Геоданные и экспорт дома №5: `Unity_Walk/Assets/StreetSource/`.
- Редактируемая исходная модель дома: `house_full/Дом_полностью.blend`.
- Подробности реконструкции и лицензий: `Unity_Walk/STREET_README.md`.

## Работа

- Общайся с пользователем на русском языке. Сохраняй название корневой папки `opd`; не переименовывай папки без отдельного указания.
- Не создавай вложенный репозиторий внутри `Unity_Walk`.
- Сохраняй Unity `.meta` рядом с соответствующими исходными ресурсами.
- Не коммить кэш Unity, готовые сборки, архивы, локальные приложения и установщики. Они исключены через `.gitignore`.
- Для регенерации сцены используй меню Unity `Street / Generate editable scene`. Для сборки — `Street / Build street and Windows game` или `Unity_Walk/Build_Windows.cmd` при закрытом редакторе этого проекта.
- Для сборки Linux x86‑64 используй `Street / Build saved scene and Linux game` с активным Linux Build Profile или `-buildTarget linux64 -executeMethod StreetBuilder.BuildLinux` в пакетном режиме. Проверь запуск Linux-игры с `-streetQA`.
- Регенерация пересоздаёт сцену из генератора; учитывай это перед ручным редактированием сцены.
- Проверка готовой игры: аргументы `-streetQA -qaOutput <папка>`. Отчёт проверяет землю, перемещение и столкновение с домом и сохраняет четыре кадра. Визуально проверяй изменённые объекты перед передачей результата.
- Не заявляй о проверке сборки или запуска, если они не выполнялись.
- После каждой завершённой задачи проверь изменения и запусти доступные тесты. При успехе создай отдельный коммит, отправь ветку в hourly992/opd и создай или обнови Pull Request. В описании перечисли изменения, проверки и известные проблемы. Готовые и проверенные сборки Windows и Linux публикуй в GitHub Releases.

- Для каждого обновления добавляй отдельный отчёт в Reports/ и в описание PR. Указывай исходный коммит, изменения, результаты проверок, ограничения и замеры производительности. Для визуальных изменений прикладывай реальные парные кадры до и после с одинаковых ракурсов. Стандартные ракурсы — старт у №5, двор №7, улица с уровня глаз, южный и восточный края. При необходимости добавляй ракурс места правки.

## Локальные инструменты

Папка `tools` с портативным Blender находится вне Git. `prepare_street.py` и `export_house_unity.py` используют относительные пути проекта; для их запуска нужен Python/Blender.
